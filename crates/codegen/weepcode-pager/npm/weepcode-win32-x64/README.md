# @weepcode-official/weepcode-win32-x64

Platform-specific binary for [`@weepcode-official/weepcode`](https://www.npmjs.com/package/@weepcode-official/weepcode) on win32-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @weepcode-official/weepcode
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
